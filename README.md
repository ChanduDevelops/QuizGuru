# QuizGuru

[![License: Apache-2.0](https://img.shields.io/badge/License-Apache--2.0-blue.svg)](https://github.com/ChanduDevelops/QuizGuru/blob/main/LICENSE)

**QuizGuru** is a full-stack quiz application with a React/TypeScript frontend (powered by Vite, proxying `/api` to port `8090` in development) and a Java 25 backend built with Maven and MongoDB, packaged via a multi-stage Docker build.

- **Live Demo:** [quizguru-jrt.onrender.com](https://quizguru-jrt.onrender.com/)
- **Repository:** [ChanduDevelops/QuizGuru](https://github.com/ChanduDevelops/QuizGuru)

---

## Tech Stack

- **Frontend:** React, TypeScript, CSS, Vite (`frontend/vite.config.ts`, `frontend/package.json`)
- **Backend:** Java 25, Maven (`backend/pom.xml`), MongoDB
